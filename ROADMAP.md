# First Light release roadmap

| Checkpoint | Implemented outcome | Recording milestone |
|---|---|---|
| 01 | Identity, boot, desktop, dock, clock and Welcome | First startup |
| 02 | Independent draggable and resizable windows, focus, snap, minimize, restore and power controls | Four-window multitasking |
| 03 | Search, command palette, recents, switching, context menu and keyboard navigation | Launch without the dock |
| 04 | Persistent IndexedDB drive, file import, folders, preview and confirmed deletion | Reload a saved document |
| 05 | Notepad, music, video, gallery, calculator, calendar, paint, clock and recorder | Open a Paint drawing in Gallery |
| 06 | Terminal with drive navigation, error reporting, history and app launch | Launch Calculator with a command |
| 07 | Themes, dock, wallpaper import, focus mode, overview and animated first boot | Transform the desktop |
| 08 | Production bundle, offline worker, install manifest, Windows portable launcher, Browser, alarms and desktop widgets | Power on the final Windows download |

Each implementation milestone is recorded in DEVELOPMENT_LOG.md. Remaining device-specific checks are listed in the recording checklist.
