# Aurora wallpaper provenance

Project asset: `public/aurora.webp` (41,450 bytes, 1586 × 992). The source PNG was generated with the built-in image generation tool, then encoded as WebP for the application. The image is bundled locally and embedded into the standalone review export. The previous Daybreak SVG remains in source history and the assets directory, but is not selected by the shell.

Generation method: built-in image generation, not CLI fallback.

Prompt:

> Use case: stylized-concept. Asset type: original default wallpaper for a premium desktop operating system, landscape 16:10. Create a beautifully art-directed minimal abstract blue wallpaper with a single flowing broad translucent satin-glass ribbon folded into softly layered sweeping waves, spanning diagonally from lower left towards middle right. It should feel like a polished real consumer OS default wallpaper. Calm softly lit periwinkle blue environment; deeper royal cobalt folded surfaces and pale ice-blue rim transitions, very sophisticated subtle material depth and smooth physically plausible shading. Background seamless spacious blue with generous empty space in upper half and along edges for desktop icons. Do not make a centered logo, donut, ring, rigid geometric sculpture, or floating isolated object. Full-bleed organic flowing forms merging into the background. Soft studio light, smooth untextured surfaces, no particles, no neon, no bloom, no lens flares, no noise, no decorations. Absolutely no text, lettering, UI, icons, branding, watermark or device frame.

The generated wallpaper was visually inspected. It contains no controls: all interactive interface elements are actual HTML, CSS and TypeScript.
